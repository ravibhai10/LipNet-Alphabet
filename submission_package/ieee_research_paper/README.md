# IEEE-style extended research manuscript

The PDF contains exactly 20 pages. The DOCX is editable and may repaginate in Word. All graphs are supplied as PNG, SVG, and PDF. The manuscript is author-prepared, not accepted or published by IEEE. A venue-specific template and page limit must be applied before submission.

Rebuild from repository root:

    .\.venv\Scripts\python.exe scripts/build_ieee_evidence_paper.py

Source: `submission_package/source/IEEE_Research_Paper_20_Pages.md`. `evidence_validation.json` verifies the 192 paired IDs, counts, confusion matrix and checkpoint hashes. `document_validation.json` records PDF pagination and layout. No new model was trained.
